# Google Docs and current-input deduplication

Google Docs offers Create, Get and Update actions using an existing workspace Google connection. Create makes a blank document; Get returns the provider document structure; Update appends text to the first tab or replaces matching text in all tabs, following the provider defaults. Document selection reuses Drive discovery and also accepts an ID or expression. Google Docs API must be enabled for the OAuth Cloud project. No additional OAuth scopes are requested by this implementation; the existing Google connection requests Drive and Sheets access. Google data-access review remains separate from API enablement.

Writes may have an uncertain outcome after a timeout, redirect or server failure; they are not automatically retried. Check the document before repeating a live write. Mock runs do not contact Google. Access depends on the user's actual Google permissions, the API being enabled and the provider's verification state; no live qualification is implied by this document.

Remove Duplicates processes only the current input list and preserves the first matching item and its provenance. It supports all fields, selected paths or all fields except selected paths. Object key order does not change equality; array order does. Missing values differ from explicit null. Suggestions come from the selected execution output, with manual field paths as a fallback. Existing limits of 100 items and 1 MB apply. Historical cross-execution deduplication is not implemented.

References: [n8n Remove Duplicates](https://docs.n8n.io/integrations/builtin/core-nodes/n8n-nodes-base.removeduplicates/), [n8n Google Docs](https://docs.n8n.io/integrations/builtin/app-nodes/n8n-nodes-base.googledocs/), [Google documents.create](https://developers.google.com/workspace/docs/api/reference/rest/v1/documents/create), [Google documents.get](https://developers.google.com/workspace/docs/api/reference/rest/v1/documents/get), [Google documents.batchUpdate](https://developers.google.com/workspace/docs/api/reference/rest/v1/documents/batchUpdate), [Google Docs authorization](https://developers.google.com/workspace/docs/api/auth).
