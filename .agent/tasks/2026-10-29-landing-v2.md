## Scope and boundaries

- Keep the existing public root and `/login` boundary.
- Build Fluxora-specific hero, product showcase, narrative, illustrative usage
  meter, FAQ, CTA, and footer from local semantic React/CSS/Motion components.
- Reuse bounded R3F islands only; no fixed full-page canvas, Lenis, external

- Preserve keyboard behavior, visible focus, `prefers-reduced-motion`, no-WebGL
  fallback, and readable server-rendered content.

- [x] Desktop/tablet/mobile, reduced-motion, and no-WebGL paths are covered by

- [x] `npm run verify` passes with no provider or deployment action.
