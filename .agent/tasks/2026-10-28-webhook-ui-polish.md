# Webhook and resource picker usability

## Target slice IDs

- `WEBHOOK-UI-POLISH-1`

## Outcome

Separate resource picker controls visually, demote manual entry to a secondary
action, and make webhook setup discoverable from the selected trigger. Ensure
the registration panel remains accessible on narrow editor layouts.

## Proof

Browser tests cover spacing, the node entry point, narrow-screen panel
interaction, and existing registration flows. Check both themes without using
real provider credentials. Run the quality gate.
