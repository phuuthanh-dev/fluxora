# Clean-room public landing v2 report

## Delivered

- Reworked the public root into a Fluxora-specific marketing journey:
  navigation, hero, product execution proof, principles, workflow narrative,
  lifecycle, illustrative usage meter, example, FAQ, CTA, and footer.
- Added accessible client interactions only where needed: a native range input
  for illustrative usage planning and native button-based FAQ disclosure.
- Extended the landing regression suite for navigation anchors, the usage
  meter, disclosure state, and a narrow mobile viewport.
- Added `docs/22-public-landing-v2.md` as the long-term route contract.

## Deliberate boundaries

- No Relay/Templify source, copy, font, image, video, or renderer is imported.
- No Lenis, scroll hijacking, fixed full-page canvas, external media/model,
  post-processing, or commercial pricing claim was added.
- Existing R3F islands remain decorative, lazy, bounded, reduced-motion-safe,
  and isolated to the public landing. Dashboard/editor/authentication do not
  import the marketing animation stack.

## Evidence

- Focused `e2e/landing.spec.ts`: 6 passed, including reduced-motion, no-WebGL,
  interactive controls, tablet, and narrow mobile coverage.
- Chromium desktop and iPhone 13 visual review completed; tablet layout has
  dedicated browser regression coverage.
- `npm run verify` passed: API 213, web 23, and Playwright 47.
