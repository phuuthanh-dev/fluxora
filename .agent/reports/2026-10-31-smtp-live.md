# SMTP live qualification — 2026-10-31

The owner entered a workspace SMTP credential directly into the local
application and authorized one test email to an owner-specified address.
A separate manual-trigger workflow published version 1 and ran once in live
mode. The SMTP node reported success and `delivered: true` for one recipient,
with a message ID. This means the SMTP submission was accepted; it does not
prove inbox placement or receipt. The test workflow was deactivated afterward.

This is one Gmail SMTP submission using STARTTLS on port 587. It does not prove
production deployment, other SMTP servers, sustained delivery or inbox placement.
